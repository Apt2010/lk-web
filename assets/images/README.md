# assets/images/

Place your project images here.

Suggested files:
- logo.png          → Company logo (transparent background, ~200×60px)
- og-image.jpg      → Open Graph / social share image (~1200×630px)
- about.jpg         → About section photo (construction team / site)
- hero-bg.jpg       → Optional hero background image
- projects/         → Subfolder for individual project photos
  - project-1.jpg
  - project-2.jpg
  - ...

To use an image in index.html, reference it as:
  src="assets/images/about.jpg"
